CARA PAKAI

Download dalam 3 langkah

01

Install & Jalankan

Install via pip lalu jalankan parth-dl serve. Server lokal akan aktif di port 8003.

02

Paste URL

Salin link Instagram yang ingin didownload lalu tempel ke kolom di atas dan pilih kualitas yang diinginkan.

03

File Tersimpan

File langsung tersimpan ke folder downloads/ lokal. Klik "Download salinan" untuk simpan lewat browser.

INFO

Hanya untuk konten publik.

parth-dl bekerja tanpa login, cookies, atau token Instagram. Tool ini hanya bisa mengunduh konten dari akun yang tidak di-private. Gunakan sesuai ketentuan Instagram dan hanya untuk konten yang memang boleh diunduh.
